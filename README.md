One word, at most 99 characters, that an agent says when it has no idea what to do: **recalculating** — the sound of a machine that has lost the plot and is buying time by pretending it has a plan.

## Run it

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
